# Order Management API

![Status](https://img.shields.io/badge/status-in%20progress-yellow)

A production-style e-commerce backend API — product catalog, cart, and order management — built with Django REST Framework, PostgreSQL, Celery, and Redis.

> 🚧 **Currently in progress.** Custom user model and project setup are complete. Product catalog, cart, checkout, async email via Celery, and Redis caching are actively being built.

## Planned Features

- Custom User Model
- Product & Category catalog
- Cart management
- Order checkout flow
- Async order confirmation emails via Celery
- Redis caching for product listings
- Token authentication
- Fully tested
- Dockerized (Django + PostgreSQL + Redis + Celery worker)
- Deployed live

## Tech Stack

- **Backend:** Python, Django, Django REST Framework
- **Database:** PostgreSQL
- **Task Queue:** Celery
- **Broker/Cache:** Redis
- **Containerization:** Docker, Docker Compose
